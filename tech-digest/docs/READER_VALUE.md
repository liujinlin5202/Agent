# 研究型技术正文：本地使用说明

规则版本：`research-v1`，稿件结构版本：2。本地实现与离线回归已完成。2026-10-12 用户授权部署，发布通过 GitHub `main` 进入秋坞仓库模式；部署后的提交与运行核验单独记录。

## 内容如何改变

正文围绕一个技术问题，解释方法或推理、对应证据、比较条件、局限和可以带走的认识。首屏先说明问题与核心发现；术语在首次使用处解释；短段落和具体小标题便于扫描。只有真正需要比较时使用小表格，不默认搬运论文全文。

资源推荐、课程推广、工具清单及广告不参与日报选稿。公司署名的技术研究只要方法与证据充分仍可入选。理论文章用假设、推导和证明，工程文章用测量及约束，不要求所有文章伪造一组实验数字。操作步骤仅在帮助解释机制或检验结论时出现。

作者报告与独立实测分开标明。自动流程固定为“未独立复现”。版本、日期、发表状态无法确定时保留未知，不用爬取日期代替发表日期。研究阶段在内容池保留来源块与证据包，用于回查；模型提示只读取选定的块，避免把完整归档重复塞进上下文。

## 离线预览

在 `tech-digest` 目录执行：

```powershell
python scripts/preview_reader_article.py --input docs/examples/research-reader/lost-in-the-middle.json --output-dir ../_preview/reader-value/lost-in-the-middle
```

输出 `body.md`、`preview.html`、`check.json`。预览包含桌面、360px、320px 选项。正文仅使用现有 Markdown 能力；宽度选项属于本地预览器。必要的代码、表格或可读公式内部可滚动，不将核心知识折叠起来。

脚本不导入配置、数据库、采样、登录和发布模块，不读取密钥，也不调用模型。运行期需要的渲染资源保存在 `scripts/preview_assets/`，HTML 会内嵌资源并限制网络请求。输入中的 HTML 只转换为正文内容，不允许样式和脚本进入最终正文。

`check.json.valid` 只代表结构、来源引用和 Markdown 校验通过，不能证明语义事实正确。示例属于人工整理的编辑样稿；自动模型效果仍需真实候选的离线审阅。不要用 `main.py daily --dry-run` 代替预览，它沿用业务流程中的登录校验等行为。

## 质量跳过和重跑

日报的内容池和即时抓取都进入同一研究流程。最终入口再次检查绑定到相同来源、最终标题、完整正文的终审结果。

| 状态 | 处理 |
| --- | --- |
| `ready` | 可生成正式快照，随后进入已有发布流程 |
| `skip_quality` | 保存独立草稿/运行原因，跳过本次；不占正式期数 |
| `generation_error` | 保存错误原因及已有草稿，等待后续重试 |

旧规则的缓存不会作为新规则审核结果。改标题、正文、来源或署名/发表日期等 metadata 后重新审核；抓取时刻变化不使相同材料无故重算。最多处理三篇，每篇最多修改一次。已发布的同一天重跑不会再发布，也不会误消费新的候选。

最终正文在审核前去掉首尾空白，并采用与发布器一致的 9,000 字符上限。超长稿退回修改或跳过；不会在发布阶段截断代码、结论或来源。审核哈希、记录的正文长度与实际提交字符串保持一致。

仅 PDF、摘要页或依赖尚未核对图表的材料会跳过。二手论文报道只跟随原文中实际存在的 HTTPS 论文链接；首版支持 arXiv、ACL、OpenReview、PMLR。原论文仍缺方法或证据时弃稿，不将二手报道补想象成完整研究。

## 本地表现复盘

```powershell
python scripts/content_report.py report --db path/to/offline-copy.db --split 2026-10-11
```

使用稳定、完整的离线 SQLite 副本。报告只读，不迁移表、不采样、不访问服务器；非空未合并 WAL 会明确拒绝，避免读取过期统计。数据库不存在时输出“无本地数据”。不要通过这份说明运行 `sample`。

发布日志保存本地确认时刻（UTC、标注 `local_confirmation`）、内容版本、类型与学习问题。采样按实际时间差选 21–27 小时，时间依据缺失则单独标注次日近似。浏览、赞和评论的比值取同一条快照，最新累计数单列。报表按版本、采样口径分组，展示 N、均值、中位数和原始分子分母。

成功日报发布的 metadata 随现有 90 天观测窗口保留，不被普通日志的 500 条上限提前挤掉。实际发布后还需要积累数据；离线测试与人工样稿不能证明浏览或读完率改善。

### 当前历史基线

此次隔离工作区没有历史数据库/导出记录，因此最近 10–20 篇基线尚无数据。可用记录数为 0；浏览、赞评和时间窗口均缺失。测试数据没有充当平台历史数据。不能根据离线测试宣称浏览或读完率提高。
